# nvim-conf

Personal Neovim config.

I use this repo to keep the bits I care about in one
place and easy to move between machines.

## What's Here

- `config/` has my basic options, keymaps, and autocmds.
- `plugins/` has the plugin tweaks I want to keep.
- `lazy-lock.json`, if present, should be committed so plugin versions stay
  predictable.
